Headphones or earbuds. First screen is a steady reference tone: set the volume there until it is where you want it, then do not touch the volume again — the whole test is at one level and changing it mid-run voids the measurement. You will be asked how loud that reference felt, which is what makes two runs comparable.

Twelve slots, eight seconds each. Beeps count the slot. Some slots are silent — neither of us knows which until you finish, and the nine real ones now arrive in a random order instead of descending, so nothing about the sequence can be anticipated.

One tap per slot, from one set of words. Tap as many as fit; tap Nothing if there is nothing. A slot you leave untapped is recorded as untapped, not as empty.
